## The screenshot build

The screenshots were captured from a build made from the **same source at the
same commit**, differing in one respect: it was compiled without a backend
address, so the application runs against bundled sample data instead of
contacting a live server.

This was deliberate. It means every name, phone number, trip and amount in the
screenshots is demonstration data generated by the application itself — no real
person's data appears anywhere in this record — and the screens are reproducible
by anyone holding the build, without access to servers or accounts.

areas appear as flat grey panels. The surrounding interface is unaffected. The
map component is present and functional in the distributed build.
